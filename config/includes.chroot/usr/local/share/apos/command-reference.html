📖 Справочник команд ApOS

Базовый набор терминальных команд для ежедневной работы.

Файлы и папки

КомандаЧто делает
lsПоказать содержимое папки
cd путьПерейти в папку
cp файл1 файл2Скопировать файл
mv файл1 файл2Переместить/переименовать
rm файлУдалить файл
mkdir папкаСоздать папку

Пакеты и обновления

КомандаЧто делает
sudo apt updateОбновить список пакетов
sudo apt upgradeУстановить обновления
sudo apt install имяУстановить программу
sudo apt remove имяУдалить программу

Система

КомандаЧто делает
htopДиспетчер задач в терминале
df -hМесто на дисках
free -hИспользование памяти
sudo rebootПерезагрузка
sudo shutdown nowВыключение

Wine (Windows-приложения)

КомандаЧто делает
wine программа.exeЗапустить .exe через Wine
winetricksУстановить доп. библиотеки/шрифты для Wine
playonlinuxГрафический менеджер Windows-программ
