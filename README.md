# ApOS — сборка своего дистрибутива на базе Debian

## Что тут лежит
```
ApOS-build/
├── build.sh                     ← главный скрипт сборки ISO
├── branding/apos-logo.svg       ← логотип
└── config/
    ├── package-lists/apos-base.list.chroot   ← что установится в систему
    ├── includes.chroot/          ← файлы, которые лягут прямо в систему
    │   ├── etc/os-release                    ← имя ОС "ApOS"
    │   ├── etc/calamares/...                 ← установщик + выбор ПО
    │   ├── etc/skel/.config/.../xfce4-panel.xml ← минималистичная панель
    │   └── usr/local/.../command-reference.html ← справочник команд
    └── hooks/normal/0100-wine-repo.hook.chroot  ← подключение Wine
```

## Важно понимать
Полноценная ОС — это не "один файл кода", а сборка реального дистрибутива
(ядро + пакеты + окружение) специальным инструментом — **live-build**.
Он берёт официальные пакеты Debian и по нашим настройкам собирает из них
загрузочный ISO. Это стандартный способ, которым пользуются десятки
маленьких дистрибутивов (в том числе и решения на основе Ubuntu/Mint).
Собрать ISO нужно у себя — я не могу скачать интернет-пакеты в этой сессии.

## Шаг 1. Собери ISO — САМЫЙ ПРОСТОЙ СПОСОБ: через GitHub Actions
Сборка происходит не у тебя на компьютере, а в облаке GitHub — бесплатно.

1. Зайди на github.com, создай новый **публичный** репозиторий (например `apos-build`).
2. Загрузи в него все файлы из этого архива (через "Add file → Upload files"
   в браузере, или `git push`, если умеешь).
3. Открой вкладку **Actions** в репозитории → слева выбери
   **"Build ApOS ISO"** → кнопка **"Run workflow"** → Run.
4. Подожди 30-60 минут (billing-время GitHub, не твоего компьютера — можно
   закрыть вкладку и вернуться позже).
5. Когда сборка завершится зелёной галочкой — зайди в неё, внизу раздел
   **Artifacts** → скачай `ApOS-iso.zip`, внутри будет готовый `ApOS.iso`.

Бесплатного лимита GitHub Actions (2000 минут/месяц) с запасом хватает
на несколько сборок.

## Шаг 1 (альтернатива). Собрать самому на своей машине
Нужна любая Debian- или Ubuntu-машина (можно виртуалка) с интернетом:

```bash
chmod +x build.sh
./build.sh
```

Процесс скачает ~2-4 ГБ пакетов и соберёт файл:
```
live-image-amd64.hybrid.iso
```
Переименуй его в `ApOS.iso`.

**Почему это не может занять 1-2 минуты:** даже на мощном сервере
скачивание нескольких гигабайт пакетов + сборка файловой системы —
это минимум 20-40 минут физически, независимо от того, кто и где
собирает. Единственное, что реально ускоряет процесс для тебя —
не сидеть и не ждать самому, а поручить это GitHub (способ выше).

## Шаг 2. Как это работает "изнутри" (коротко)
- **Ядро** — стандартное ядро Linux из репозитория Debian (то же, на чём
  фактически основаны и Ubuntu, и Mint).
- **Рабочий стол** — XFCE: лёгкий, быстрый, с минималистичной панелью
  (конфиг уже прописан — одно меню, трей, часы, ничего лишнего).
- **Установщик** — Calamares (тот же, что использует Mint). Загружается
  сразу live-сессия рабочего стола — можно попользоваться, а когда
  готов — запускаешь установщик с рабочего стола.
- **Выбор ПО при установке** — экран `packagechooser` в установщике
  (галочки: офис, графика, Wine, Steam, инструменты разработчика).
- **Windows-приложения** — Wine + PlayOnLinux уже в базовом списке пакетов.
- **Справочник команд** — ярлык в меню приложений, открывает HTML-страницу
  со списком базовых команд.

## Новые функции (добавлены по запросу)
- **Timeshift** — снимки системы и откат назад, как в Mint.
- **Synaptic + GNOME Software + Flatpak/Flathub** — два магазина приложений.
- **Диспетчер обновлений ApOS** (`apos-update-manager`) — окно с одной
  кнопкой "Обновить систему".
- **Диспетчер драйверов ApOS** (`apos-driver-manager`) — сам определяет
  видеокарту NVIDIA и предлагает поставить проприетарный драйвер.
- **Экран приветствия** — при первом входе показывает краткий гайд по
  системе (один раз, дальше не всплывает).
- **Gufw** — простой графический firewall.
- **Redshift** — ночной режим экрана (тёплый оттенок вечером).
- **Clipman** — менеджер буфера обмена в панели.
- **unattended-upgrades** — фоновые автоматические обновления безопасности.

## Визуальная идентичность ApOS (не просто Debian с другим именем)
- **Свои обои** (`apos-wallpaper.png`) — сгенерированы отдельно, фирменный
  тёмно-сине-фиолетовый градиент с геометрическим узором и логотипом.
- **Chromium вместо Firefox** — другой набор софта по умолчанию.
- **Тёмная тема Arc-Dark + иконки Papirus-Dark** — вместо стандартной
  светлой Debian-темы.
- **Фирменный экран загрузки (Plymouth)** — тёмный фон + логотип по центру
  вместо стандартного логотипа Debian при старте.
- **Свой фон и тема экрана входа (LightDM)** — те же обои и Arc-Dark.
- **Автовход в графику под пользователем apos** (пароль по умолчанию: apos)
  — раньше без этого после загрузки было видно только консоль, из-за чего
  казалось, что графики вообще нет.

## Шаг 3. Запись готового ApOS.iso на флешку

### Windows
1. Скачай **Rufus** (rufus.ie).
2. Вставь флешку (её содержимое сотрутся!).
3. В Rufus выбери `ApOS.iso`, режим записи — **DD Image** (это важно для
   гибридного ISO), нажми «Старт».

### Linux
```bash
# Узнать имя флешки (например /dev/sdb) — НЕ раздела (не /dev/sdb1!)
lsblk

sudo dd if=ApOS.iso of=/dev/sdX bs=4M status=progress oflag=sync
```
Замени `/dev/sdX` на своё устройство.

### macOS
```bash
diskutil list
sudo dd if=ApOS.iso of=/dev/rdiskN bs=4m
```

### Универсально (без потери прошлых файлов на флешке)
Можно использовать **Ventoy** — записывается один раз, а дальше просто
копируешь любые .iso (в том числе ApOS.iso) на флешку как обычные файлы,
и при загрузке выбираешь нужный.

## Шаг 4. Загрузка и установка
1. В BIOS/UEFI выбери загрузку с USB (обычно F12/F2/Esc при старте).
2. Загрузится живой рабочий стол ApOS — можно всё потыкать без установки.
3. Когда решишь установить — открой ярлык «Установить ApOS» на рабочем
   столе, пройди мастер Calamares (диск, пользователь, выбор ПО).

## Что доработать дальше (по желанию)
- Заменить логотип/обои на свой дизайн (файлы в `branding/` и
  `config/includes.chroot/usr/share/backgrounds/`).
- Добавить свою тему Plymouth (экран загрузки).
- Расширить/сократить `apos-base.list.chroot` под свои нужды.
- Официальная документация live-build: https://live-team.pages.debian.net/live-manual/
- Официальная документация Calamares: https://calamares.io/docs/
